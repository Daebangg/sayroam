Google 버튼은 테마와 무관하게 흰 배경을 사용합니다. 네이버 원본 아이콘은 배경까지 보존하고
화면에서는 심볼 부분만 표시합니다. 공급자 로고를 공용 UI 아이콘으로 대체하지 않습니다.
자산 표시는 OAuth 등록·인증 연결을 의미하지 않습니다.
