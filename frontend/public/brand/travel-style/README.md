# 여행 스타일 선택 일러스트

사용자가 제공한 큐비드 아이콘 보드를 기준으로 제작한 투명 배경 WebP 자산입니다.
프로필 기본 아이콘과 같은 파랑·하늘색·네이비·모래색 색면과 부드러운 음영을 사용합니다.

- 기본 제공 image_gen 도구로 원본 보드를 정리하고 같은 질감으로 재제작했습니다.
- 인물 5종은 옆모습·모자·배낭·하이파이브 자세를 유지하되, 기본 프로필 아바타의 각진 얼굴·기하학적 머리카락·코·안경 표현을 적용했습니다. 눈과 입은 표시하지 않습니다.
- 운동화는 밑창·끈·뒤꿈치와 속도선을 구분합니다.
- 적당히 쓰기는 겹쳐진 지폐이며, 돈보다 경험은 왕관 카드가 아닌 정상에 깃발이 꽂힌 산입니다.
- 각 이미지는 256×256 픽셀, 무손실 WebP, 투명 배경입니다.
- 기본 Icon의 style-* 브랜드 변형과 여행 스타일 선택 카드에서 사용합니다.
- 외곽선 변형은 상위 travel-style-icons.svg에서 제공합니다.

## 제작 프롬프트

제공된 20개 아이콘 보드의 세밀한 기하학 색면, 부드러운 그라데이션, 인물의 옆모습과 모자,
운동화·지폐의 형태를 보존한다. 글자·구분선·흰 배경을 제거하고 5열×4행의 투명 보드로 정리한다.
단순한 도형이나 픽토그램으로 축약하지 않는다. 마지막 왕관 카드는 같은 질감의 파란 산과
정상에 꽂힌 금색 깃발로 교체한다. 원본과 같은 팔레트와 완성도를 유지하고 레이블은 넣지 않는다.

제작한 보드를 개별 아이콘으로 분리한 뒤 공통 캔버스와 여백을 적용했습니다.

## 인물 스타일 보정 프롬프트

기본 프로필의 여행자·햇살·사색·탐험가 인물 아바타를 스타일 기준으로 사용한다.
날카롭고 비대칭인 다각형 얼굴 색면, 네이비·파랑 머리카락, 모래색 피부, 작은 눈과 삼각형 코,
절제된 미소와 둥근 안경을 표현한다. 기존 다섯 선택지의 배낭을 멘 단독 여행자·서로 떨어진 두 사람·
대칭으로 나뉜 두 사람·함께 선 두 사람·하이파이브하는 두 사람 구도를 유지한다.
각 인물을 투명 배경에 분리하고 원형 프레임이나 문구는 넣지 않는다.

## 얼굴·모자 후속 보정

사용자 요청에 따라 모든 인물의 눈(흰자·동공 포함)과 입을 제거하고 주변 피부 색면으로 채웠습니다.
코와 안경, 기존 자세는 유지합니다. 반반이 좋아요 아이콘의 여성 모자는 배경 반원처럼 보이지 않도록
모자 몸통을 작게 정리하고 네이비 띠, 모자 챙과 아래쪽 그림자를 분리했습니다.

반반 아이콘의 남성도 단독 여행자 아이콘을 기준으로 보정했습니다. 모자가 커다란 반원이나
중앙에서 잘린 배경으로 보이지 않도록 정상적인 캡 모자 크기와 뒤통수 윤곽으로 바꾸고,
머리 뒤쪽은 투명 여백으로 분리했습니다. 여성 모자와 눈·입이 없는 표현은 유지했습니다.

## 반반이 좋아요 최종 구도

최종 요청은 서로 다른 곳을 바라보는 분할 구도 대신 두 사람이 서로를 보며 가볍게 손 인사하는 모습입니다.
남성은 왼쪽, 여성은 오른쪽에 같은 비중으로 배치하고 각자 어깨 높이에서 한 손을 들어 인사합니다.
다섯 번째 하이파이브와 구분하도록 두 손은 맞닿지 않으며, 눈과 입이 없는 큐비드 인물 스타일을 유지합니다.

사용자가 제공한 손 인사 참고 이미지에 맞춰 손바닥을 얼굴 옆에 세우고 손가락을 위로 자연스럽게
펼쳤습니다. 손목은 과하게 꺾이지 않도록 팔과 이어지며, 각 손 위에는 짧은 파란 곡선 두 개로
흔드는 동작을 표시합니다. 참고 이미지에서는 손짓만 반영하고 기존 인물과 눈·입 없는 얼굴은 유지합니다.
