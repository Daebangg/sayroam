# 화면 유형별 정합성 규칙

화면을 추가·수정할 때 같은 유형의 기준 화면과 공용 스타일을 사용합니다. 셸·본문 폭·제목 간격·표면·
타이포그래피·액션 위치를 공유하되 서로 다른 유형을 같은 크기로 강제하지 않습니다.

| 유형           | 기준 소유자                                              | 공유 규칙                                            |
| -------------- | -------------------------------------------------------- | ---------------------------------------------------- |
| 공개 홈        | `pages/home/HomePage.tsx`                                | 산 배경·손글씨 제목·소개·시작 버튼                   |
| 앱 셸          | `components/layout/AppShell.tsx`                         | 데스크톱 상단 메뉴·모바일 하단 메뉴·브랜드·공용 액션 |
| 여행 카드      | `pages/trips/TripsPage.tsx`                              | 사진·제목·날짜·멤버·카드 표면                        |
| 동행 목록      | `pages/matching/MatchingPage.tsx`                        | 사진·제목·일정·인원·저장 액션                        |
| 방 목록        | `pages/rooms/RoomsPage.tsx`                              | 원형 사진·이름·최근 메시지·화살표                    |
| 인증 모달      | `components/features/auth/AuthPreview.tsx`, 공용 `Modal` | 닫기·중앙 제목·공급자 버튼·구분선·포커스             |
| 브랜드·공용 UI | `pages/brand/BrandPage.tsx`                              | 로고·팔레트·아이콘·공용 버튼 예시                    |

현재 화면은 #60의 정적 초안입니다. 목록·제목·일정·인원·메시지는 예시이며 실제 계정·요청과 연결하지 않습니다.
화면·언어·테마·모달은 미리보기 상태만 전환합니다.

배치가 달라지는 변경은 영향을 받는 대표 화면에서 잘림·겹침·스크롤·클릭 영역을 확인합니다.
모바일 배치를 바꾸면 모바일, 데스크톱 배치를 바꾸면 데스크톱을 확인하고 공통 배치를 바꾸면 양쪽을 확인합니다.
390px와 1440px는 대표 기준이며 매번 모든 폭·테마·언어 조합이나 별도 근거 양식을 강제하지 않습니다.
문구·문서만 수정하거나 기존 검사 결과가 유효하면 관련 범위만 확인하고 검사를 반복하지 않습니다.

자동 검사만으로 시각적 동일성을 보장했다고 기록하지 않습니다. 동작 줄이기·키보드 포커스를 유지하고,
새로운 업무 기능의 회귀 검사는 해당 기능 구현 범위에서 정합니다.

## 공용 UI와 자동 검사

- 카드의 공통 표면은 `components/ui/cards/Card.tsx`가 소유합니다. 여행·동행 카드와 쇼케이스가 같은 컴포넌트를 사용하며 모바일 동행 목록의 평면형 배치는 유지합니다.
- 버튼은 공용 `Button`을 사용합니다. 내비게이션·브랜드·텍스트 링크처럼 배치가 다른 버튼은 `variant="plain"`으로 의미·기본 type·ref 처리를 공유하고 기존 레이아웃 클래스를 적용합니다.
- `TextField`의 `hint`·`error`는 입력의 `aria-describedby`와 연결하고 오류에는 `aria-invalid`를 적용합니다. 실제 업무 검증과 API 오류 연결은 각 기능에서 수행합니다.
- 브랜드 보기(`?view=brand`)에서 기본·선택·로딩·비활성·입력 오류·긴 문구를 확인합니다. 호버는 포인터, 포커스는 Tab·Shift+Tab으로 실제 공용 컴포넌트를 조작해 비교합니다.

`pnpm lint`는 페이지·기능·레이아웃의 직접 button/input/select/textarea, JSX 외형 스타일·문구 리터럴을 검사합니다.
`pnpm ui:check`는 `src/styles/app.css` 외 스타일 파일과 동일 CSS 규칙 안의 같은 속성·값 중복 선언을 검사합니다.
다른 값의 브라우저 대체 선언은 허용합니다. `pnpm check`에 두 검사를 포함합니다.

별칭으로 감춘 DOM, 화면 사이의 의미상 중복 CSS, 실제 색상 대비·잘림·포커스 순서까지 자동으로 보장하지 않습니다.
이 부분은 390px·1440px의 대표 화면, 밝은·어두운 테마와 긴 번역문에서 브라우저로 확인합니다.
